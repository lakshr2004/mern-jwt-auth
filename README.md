# 🔐 MERN JWT Authentication System

A full-stack authentication system built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with secure JWT-based authentication and protected routes.

---

## 🚀 Features

- User Registration
- User Login
- JWT Token Authentication
- Protected Backend Routes
- Protected Frontend Routes
- Logout Functionality
- Axios Interceptor for Token Handling
- Secure Environment Variable Management
- Modern Styled UI (Login, Register, Profile)

---

## 🛠 Tech Stack

### Frontend
- React.js (Vite)
- React Router DOM
- Axios
- Custom CSS Styling

### Backend
- Node.js
- Express.js
- MongoDB (Atlas)
- Mongoose
- JSON Web Token (JWT)
- Bcrypt.js
- CORS
- dotenv
